# Spec: Rename to Repo Backups & Custom Design-System Favicon

## Objective
Align platform naming and visual identity by:
1. Renaming the platform from "Repo Manage" to "Repo Backups" across user-facing copy, document metadata, top navigation, login views, and footer.
2. Renaming technical and infrastructure identifiers (`package.json`, Docker compose, deployment scripts, fallback slugs, client user agents, demo S3 buckets).
3. Replacing the default Next.js template favicon with a custom warm-canvas editorial favicon (4-spoke radial starburst mark on a dark navy squircle with warm coral spokes) delivered via scalable vector `app/icon.svg` and `app/favicon.ico`.
4. Updating test assertions and domain glossary.
